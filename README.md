# Gabriel Franco Rita — Cybersecurity Portfolio

A static HTML/CSS portfolio prepared for deployment on Vercel.

## Included
- `index.html` — responsive portfolio landing page
- `assets/` — project reports (PDF and editable DOCX) and Fortinet course completion certificates (PDF)

## Deploy to Vercel
1. Extract this ZIP.
2. Upload the contents of the `cybersecurity-portfolio` folder to a GitHub repository (keep `index.html` and `assets/` together at the repository root).
3. In Vercel, choose **Add New → Project**, import the repository, and deploy.
4. For a plain HTML site, no build command is required. Leave the output directory unset/default, or set it to `.` if prompted.

## Personalize before publishing
- Replace the email placeholder `your.email@example.com` in `index.html` with an email address you want to publish.
- Add a profile photo or links to professional profiles if desired.
- Review all documents before making them public. The included lab reports contain technical details and screenshots; only publish content you are comfortable sharing publicly.

All lab activities are presented as learning exercises in controlled/authorized environments.
